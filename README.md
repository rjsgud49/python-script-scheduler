## Overview

**python-script-scheduler** is a desktop application that simplifies the management, scheduling, and execution of Python scripts located in `C:\python`. It offers both manual and automated scheduled runs, with real-time logging to monitor performance and troubleshoot issues seamlessly.

### Why python-script-scheduler?

This project provides a comprehensive solution for automating Python workflows within a user-friendly desktop environment. The core features include:

- 🧩 **🗓️ Scheduling & Automation:** Easily set up and manage scheduled runs for your scripts, ensuring timely execution without manual intervention.
- 🖥️ **🎯 Real-time Monitoring:** View live logs and script outputs to track performance and troubleshoot issues instantly.
- 🔧 **🔄 Script Management:** Manually execute scripts or automate repetitive tasks with minimal effort.
- 🌐 **⚙️ Electron Integration:** Leverage a modern UI to control, monitor, and configure your automation workflows effortlessly.
- 📊 **🔍 Performance Insights:** Gain visibility into script execution and system performance within a cohesive desktop app.

## Getting Started

### Prerequisites

This project requires the following dependencies:

- **Programming Language:** JavaScript  
- **Package Manager:** npm  

---

### Installation

Build **python-script-scheduler** from the source and install dependencies:

1. **Clone the repository:**
   ```sh
   git clone https://github.com/rjsgud49/python-script-scheduler
   ```

2. **Navigate to the project directory:**
   ```sh
   cd python-script-scheduler
   ```

3. **Install the dependencies:**
   ```sh
   npm install
   ```

---

### Usage

Run the project with:

```sh
npm start
```

---

### Testing

Python-script-scheduler uses the **{test_framework}** test framework. Run the test suite with:

```sh
npm test
```
